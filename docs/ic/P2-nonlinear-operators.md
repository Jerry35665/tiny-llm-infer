## 1. 算子对照表

| 提案（BERT 系） | 本项目（Qwen 系） | 说明 |
|---|---|---|
| LayerNorm | RMSNorm | RMSNorm = LayerNorm 去掉均值中心化；硬件少一次全和与减法 |
| GELU | SwiGLU（silu(gate)·up） | 同为平滑门控激活，硬件都要 sigmoid 类非线性 |
| Softmax（减最大值） | 同 | 数值稳定技巧，硬件映射见 §3 |
| QKV 投影 | 同 + GQA | GQA 让 KV 带宽/显存省 7×（M2 里算账） |

## 2. 超越函数的硬件化（exp / sigmoid）

软件里 `expf` 一次 ~20 cycle；硬件没有"ALU 调用"可蹭，三条路：

| 方案 | 原理 | 精度 | 延迟 | 面积 |
|---|---|---|---|---|
| **LUT + 线性插值** | exp(x)=2^(x·log₂e)，拆整数/小数段，小数查表+斜率乘加 | ~2^(-k)，k=表位宽 | 1~2 cycle | SRAM |
| **CORDIC** | 迭代旋转，只需加法+移位 | 迭代数决定（~16~24 层） | 16~24 cycle | 最省（无乘法器） |
| **Minimax 多项式** | 切比雪夫/极小化最大逼近 | 可控到很高 | 最短 | 需乘法器 |

取舍 = **面积 ↔ 精度 ↔ T_clk** 三角。LLM 推理里 softmax 的 exp 相对误差 ~1e-3 即可
（对照 M1 对拍容差的误差预算思维）。

## 3. 减最大值 → 比较器树

软件：`m = max(x)` 一行；硬件：N 路输入 → log₂N 深度比较器树。
vocab=151936 → 18 层树，直接进关键路径会拖 T_clk → 工程做法是分块 reduce +
流水线化（每块内部树、块间寄存器打拍）。这正是"软件一行、硬件一栋楼"的典型例子。

## 4. RSQRT（RMSNorm 的 1/sqrt）

硬件路线：查表给初始猜测 + Newton-Raphson 迭代 2~3 次；GPU 里对应 SFU 的
rsqrt.approx 指令。误差与迭代次数的关系值得在 M1 后用数值实验验证一遍。

## 6. 面试一句话

"非线性算子的硬件化是查表、迭代、多项式三选一，选哪个取决于面积/精度/主频的三角；
softmax 的减最大值在硬件里是深度 log₂N 的比较器树，要流水化才不拖 T_clk。"
